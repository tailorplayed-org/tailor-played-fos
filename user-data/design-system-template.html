TailorPlayed Design System

The complete "Design DNA" for building TP-FOS — a financial dashboard that feels like a seamless extension of TailorPlayed.

v3 · Premium Elegance Theme

1. The "Vibe" Analysis

TailorPlayed communicates "Premium Elegance" — a dark-mode-first theme anchored in deep purples and rich golds. Think "a high-end board-game lounge at midnight" — warm, inviting, tactile, but undeniably polished.

Key Adjectives

✨ Magical ☀️ Warm 💎 Premium 🎲 Playful ♿ Accessible 🌙 Whimsical

Dashboard Vibe Strategy

Balancing playfulness with data density — same family, different room.

Website TraitDashboard Adaptation
Large text (18px body)→16px for tables, keep 18px for summaries
Generous spacing (24px padding)→16px card padding, 8px table cells
Heavy rounded corners (16px)→12px cards, 8px inline elements
Gold glow on hover→Reserve glow for primary CTAs only
Playful animations→fadeIn for panels; skip for data rows
Game metaphors→Finance metaphors with warm colors
The Golden Rule: A user moving from the website to the dashboard should feel at home, not like they switched apps.

Heading vs Body Contrast

Headings use $gold (#fcb700)

Body text uses $gold-light (#ffd54f) — creating a deliberate contrast hierarchy between headings and paragraphs.

Muted text uses gold at 50% opacity for helper text and timestamps.

Monospace exception: Use Courier New, monospace for Order IDs, reference codes, and hashes.

18. Accessibility Rules

Non-negotiable requirements baked into the design system. WCAG 2.1 AA + Israeli Standard 5568.

Focus Ring
outline: 2px solid #fcb700 with offset: 2px on all interactive elements via :focus-visible.
Touch Targets
Minimum 44×44px on ALL clickable/tappable elements. No exceptions.
Color Contrast
Gold on dark = 11.2:1 ratio (exceeds AAA 7:1). Never rely on color alone.
Reduced Motion
prefers-reduced-motion: reduce disables all Tier 2 & 3 animations system-wide.
RTL Support
CSS logical properties: padding-inline-start, margin-inline-end, inset-inline-start.
High Contrast
forced-colors: active ensures focus rings and borders in Windows High Contrast mode.
Screen Reader
.sr-only class for visually hidden labels. All inputs must have associated labels.
Keyboard Nav
All interactive elements reachable via Tab. Arrow keys for grids via roving tabindex.
Tab through this page to see the gold focus rings in action on all interactive elements — buttons, inputs, links, and chips.
